# Keyboard Controls & Presenter Mode

When viewing any teleprompter script in the browser, you can control scrolling, formatting, and navigation in real time using your keyboard or a wireless presentation remote.

Your preferences (font size, padding, line height, speed, and mirroring) are saved locally in the browser and will persist across scripts and sessions.

---

## Standard Keyboard Controls

### Playback & Navigation

| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>Space</kbd> | **Start / Pause Scroll** | Toggles smooth automatic scrolling. |
| <kbd>→</kbd> | **Decrease Speed** | Slows down the automatic scroll rate. |
| <kbd>←</kbd> | **Increase Speed** | Speeds up the automatic scroll rate. |
| <kbd>1</kbd> | **Scroll to Top** | Immediately scrolls back to the beginning of the script. |
| <kbd>F</kbd> | **Fullscreen** | Toggles full-screen browser view. |
| <kbd>R</kbd> | **Refresh** | Reloads the current script page. |
| <kbd>/</kbd> | **Go Back** | Navigates back to the previous page / database index. |

### Formatting & Mirroring

| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>Q</kbd> | **Decrease Font Size** | Decreases font size by the configured increment. |
| <kbd>W</kbd> | **Increase Font Size** | Increases font size by the configured increment. |
| <kbd>A</kbd> | **Decrease Padding** | Reduces left/right screen padding. |
| <kbd>S</kbd> | **Increase Padding** | Adds more left/right margin space. |
| <kbd>Z</kbd> | **Decrease Line Height** | Tightens spacing between lines of text. |
| <kbd>X</kbd> | **Increase Line Height** | Expands line height for easier reading. |
| <kbd>M</kbd> | **Mirror Screen** | Horizontally flips the text display for use with physical teleprompter glass/beamsplitter mirrors. |

### Help & Diagnostics

| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>H</kbd> | **Help Modal** | Opens/closes the in-prompter keyboard shortcuts cheat sheet. |
| <kbd>I</kbd> | **Debug Info** | Logs current settings (font size, padding, scroll speed) to browser console. |

## Wireless Presenter Remote Support

_Nprompter_ maps standard wireless presentation remotes (clickers) out of the box:

| Remote Button / Key | Action |
| :--- | :--- |
| <kbd>F5</kbd> | Toggle auto-scrolling on/off |
| <kbd>PageDown</kbd> | Increase scroll speed |
| <kbd>PageUp</kbd> | Decrease scroll speed |
| <kbd>B</kbd> | Manual step scroll down |
| <kbd>ESC</kbd> | Manual step scroll up |
