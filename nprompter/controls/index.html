    Keyboard Controls & Presenter Mode

    When viewing any teleprompter script in the browser, you can control scrolling, formatting, and navigation in real time using your keyboard or a wireless presentation remote.

    Your preferences (font size, padding, line height, speed, and mirroring) are saved locally in the browser and will persist across scripts and sessions.

    Standard Keyboard Controls

    Playback & Navigation

    Key Action Description
    Space Start / Pause Scroll Toggles smooth automatic scrolling.
    → Decrease Speed Slows down the automatic scroll rate.
    ← Increase Speed Speeds up the automatic scroll rate.
    1 Scroll to Top Immediately scrolls back to the beginning of the script.
    F Fullscreen Toggles full-screen browser view.
    R Refresh Reloads the current script page.
    / Go Back Navigates back to the previous page / database index.

    Formatting & Mirroring

    Key Action Description
    Q Decrease Font Size Decreases font size by the configured increment.
    W Increase Font Size Increases font size by the configured increment.
    A Decrease Padding Reduces left/right screen padding.
    S Increase Padding Adds more left/right margin space.
    Z Decrease Line Height Tightens spacing between lines of text.
    X Increase Line Height Expands line height for easier reading.
    M Mirror Screen Horizontally flips the text display for use with physical teleprompter glass/beamsplitter mirrors.

    Help & Diagnostics

    Key Action Description
    H Help Modal Opens/closes the in-prompter keyboard shortcuts cheat sheet.
    I Debug Info Logs current settings (font size, padding, scroll speed) to browser console.

    Wireless Presenter Remote Support

    Nprompter maps standard wireless presentation remotes (clickers) out of the box:

    Remote Button / Key Action
    F5 Toggle auto-scrolling on/off
    PageDown Increase scroll speed
    PageUp Decrease scroll speed
    B Manual step scroll down
    ESC Manual step scroll up
